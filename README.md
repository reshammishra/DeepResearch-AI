## DeepResearch-AI
ResearchPilot AI is a multi-agent research assistant built with Python and LangChain. It automates web search, content extraction, report generation, and quality evaluation using Tavily Search, web scraping, and GPT-4o-mini to deliver structured research reports with key findings, conclusions, and source references.
